# ptusa_engineer

Приложение для работы с описанием технологического процесса в экосистеме `ptusa_ai`

## Описание

Этот проект реализует визуализацию технологического процесса на C++, основанную на системе из [EasyEPLANner](https://github.com/savushkin-r-d/EasyEPLANner).

## Компоненты

### Editor

- **DrawInfo** - Класс для настройки цвета отображения на странице
  - Поддержка различных стилей отрисовки (зеленая, серая, красная рамки)
  - Типы действий с битовыми флагами для проверки конфликтов
  - Методы фильтрации устройств для подсветки
  
- **TreeViewItem** - Базовый класс для элементов дерева технологических объектов
  - Интерфейс для отображения на странице EPLAN
  - Поддержка иерархической структуры

### TechObject

- **Action** - Действия над устройствами (включение, выключение и т.д.)
  - Управление списком устройств
  - Настройка стилей отрисовки
  - Типы действий для визуализации

## Сборка

### Требования

- CMake >= 3.10
- Компилятор C++ с поддержкой C++17 (GCC, Clang, MSVC)

### Инструкции

```bash
mkdir build
cd build
cmake ..
make
```

### Запуск тестов

```bash
cd build
./tests/ptusa_engineer_tests
```

или через ctest:

```bash
cd build
ctest
```

## Архитектура

Система визуализации основана на следующих принципах:

1. **Фильтрация устройств** - группировка устройств по имени и применение правил приоритета для определения финального стиля отображения
2. **Проверка конфликтов действий** - использование битовых флагов для определения несовместимых комбинаций действий
3. **Иерархическая структура** - организация технологических объектов в виде дерева

## Особенности реализации

- Использование современного C++17
- Умные указатели (shared_ptr) для управления памятью
- Модульная архитектура
- Полное покрытие тестами (Google Test)
